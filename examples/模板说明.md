# 轴的模板零件要自己在 Creo 里做

`shaft_variants.csv` 是一张示例参数表，里面有三根轴的尺寸。

仓库里故意不放 `shaft.prt`。`.prt` 是 Creo 的零件文件，只能由 Creo 生成，不能用文本编出来。

请按下面的步骤做一根轴，并让参数名字和表格表头完全一致。

## 1. 新建零件

在 Creo 里选择「文件 → 新建 → 零件」。名字用 `shaft`。单位用毫米（公制模板，例如 `mmns_part_solid`）。

## 2. 做出形状

用旋转或拉伸做一根圆轴，并倒一个角。尺寸先随便给，例如直径 20、长度 80、倒角 1。做成功后能再生即可。

## 3. 添加四个命名参数

打开「工具 → 参数」，添加：

| 名字 | Creo 里的类型 | 含义 |
| --- | --- | --- |
| D | 实数 | 直径 |
| L | 实数 | 长度 |
| C | 实数 | 倒角 |
| MARK | 字符串 | 记号，例如 A、B、C |

名字要和表格第一行一模一样，建议全部大写。Creo 靠名字找到参数，名字差一个字母就对不上。

## 4. 用关系把尺寸绑到参数上

打开「工具 → 关系」。尺寸上显示的符号通常是 `d0`、`d1`、`d2`，以你模型里看到的为准。写成：

```
d0 = D
d1 = L
d2 = C
```

然后按「再生」。改一下参数 D 再再生，直径跟着变，就说明绑对了。

## 5. 保存

把零件保存为 `shaft.prt`，记住它所在的文件夹。运行程序时用 `--template` 指向这个文件。

## 6. 表格里每一列

- `variant`：这一行零件的名字。用英文字母开头，不要空格和中文。程序会在后面补上 `.prt`，例如 `shaft_20x80` 会变成 `shaft_20x80.prt`。
- `D`、`L`、`C`：尺寸。请写成带小数点的数，例如 `20.0`。这样会按实数（DOUBLE）交给 Creo。
- 不带小数点的数，例如 `4`，会按整数（INTEGER）交给 Creo。
- `true` / `false` 会按「是 / 否」（BOOL）交给 Creo。
- 其他文字，例如 `MARK` 列里的 `A`，按字符串（STRING）交给 Creo。

用 Excel 保存时，请选「CSV UTF-8（逗号分隔）」。
